ESL v6.3.0 is available.

This update adds tools for sticky-state tracking, animation control, and focus management.

It includes the new `ESLStickyBox` mixin, media-query-based animation disabling in `esl-animate`, the `reveal-focus-visible` carousel policy, and explicit autofocus targets for toggleables.
